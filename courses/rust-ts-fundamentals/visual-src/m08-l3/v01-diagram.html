json-rpc 2.0

one envelope, both directions

request
{
"jsonrpc": "2.0",protocol version, always "2.0"
"id": 1,correlation id you choose
"method": "getBalance",what to call
"params": ["<address>"]arguments, positional
}
id echoed
response · success
{ "jsonrpc": "2.0", "id": 1,
"result": <method-specific shape> }
result OR error, never both
response · failure
{ "jsonrpc": "2.0", "id": 1,
"error": { "code": -32601,
"message": "Method not found" } }
