the check helper contract

check () {
  local name="$1"; shift
  if "$@" >/dev/null 2>&1; then
    echo "OK   $name"
  else
    echo "FAIL $name"
  fi
}
the label the first argument is the printed label; shift drops it before the command runs
the command under test everything after the label runs as the command itself: "$@", output silenced
the verdict success is the command exiting 0, nothing else. no grepping output, no vibes.
usage: a raw command, or a bash function you define above it
check "edge 6: poller answers"  curl -fsS http://localhost:8080/status
check "edge 2: status fresh"    status_fresh   # a function defined above
