    Err(join_err) => {

    }
    Ok((target, outcome)) => {
      log_event("probe_result", …);2
      let next = …; // TODO(2): classify

        log_event("state_change", …);3

    }

}
1error
event · detail(join_err) · ts
The station itself hiccuped: a task panic, not the target. Only the Err arm knows.
2probe_result
event · target · outcome · latency_ms · ts
One per result, emitted right after now is computed, so ts is the probe’s.
3state_change
event · target · from · to · ts
Only on difference, after TODO(2) computes next. Answers “when did it flip”.
4no events here
Boundaries only: per-iteration lines are noise. The rest of the loop stays silent on purpose.
