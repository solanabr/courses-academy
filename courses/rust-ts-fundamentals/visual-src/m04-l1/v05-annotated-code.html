| { kind: "ok"; latencyMs: number }
| { kind: "timeout"; budgetMs: number }

Rust · the enum, today

enum ProbeResult {
Ok { latency_ms: u64 },
Timeout { budget_ms: u64 },
HttpError { status: u16 },
}
discriminant: the construction itself, the variant name
each variant carries exactly its own data; wrong states can’t be spelled in either
