WEB2 VS WEB3 VS THE COMPILER

the life of a wrong state: three endings

wrong state
constructed in code
web2
ships
user sees wrong data
ticket filed
patch deployed
cost: time + an apology (reversible)
web3
ships
transaction signed & sent
state change on the ledger
cost: value moved, cannot be un-happened (irreversible)
compile-time proof
wrong state has no encoding
does not compile
nothing ships. cost: a compile error, paid at your desk
the third flow terminates earliest: the bug dies before it can become a ticket or a transfer.
