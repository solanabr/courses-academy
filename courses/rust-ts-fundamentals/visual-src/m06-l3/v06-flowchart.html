ONE ENTRY POINT · TWO MODES

run-once script vs interval service

entry: parse args + FLEET_INTERVAL
no interval set: the cron's unchanged path
runSweep() once
exit 0
interval set: long-running service
loop ↺
runSweep()
abortable sleep(interval) → back to loop
SIGTERM / SIGINTAbortController fires; the sleep wakes immediately
loop condition fails → clean exit log
exit 0; docker stop comes back clean
✗ anti-pattern:  exit after one sweep + restart: always; restart churn as a fake scheduler
