app stance vs library stance

two MSRV contracts, both correct

the application

agave: validator client
rust-version = "1.98.0"
current stable, exactly
→controls its own build environment
→takes new std APIs immediately
→excludes older toolchains, and does not care

the library

carbon: indexer framework
rust-version = "1.82"
sixteen releases behind stable
→runs on strangers' toolchains
→welcomes old environments
→forbids itself newer std APIs
Both are deliberate contracts, not defaults.  Probed from live manifests, 2026-09-02.
