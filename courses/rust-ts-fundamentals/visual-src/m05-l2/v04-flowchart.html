the MSRV-aware fallback

what resolver v3 actually does

your crate declares rust-version = "1.82"
dependency X has 2.4.0 (requires rustc 1.95) and 2.1.0 (requires rustc 1.80)
resolver v2
pick newest compatible → 2.4.0
no MSRV check happens
✗ build fails on the old toolchain: 2.4.0 needs rustc 1.95, you promised 1.82
resolver v3
check candidate rust-version against yours: 2.4.0 needs 1.95 > 1.82? yes
fall back: skip 2.4.0
pick 2.1.0 (needs rustc 1.80 ≤ 1.82)
✓ builds everywhere you promised
