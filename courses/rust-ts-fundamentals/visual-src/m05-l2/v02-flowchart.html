declare once, subscribe explicitly

how a workspace dependency resolves

root Cargo.toml · [workspace.dependencies]
serde = { version = "1.0.229", features = ["derive"] }
declared once, for everyone
crates/pulse-engine · [dependencies]
serde = { workspace = true } subscribes
→ gets 1.0.229 + derive
crates/pulse-cli · [dependencies]
serde not mentioned
→ gets nothing: no subscription, no dependency
Cargo.lock: one lockfile at the root; a single resolution covers both members
