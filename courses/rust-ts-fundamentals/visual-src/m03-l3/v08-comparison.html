classify the failure first

two failure classes and where each one surfaces

failure class 1
failing build
bad commit pushed
type error, bad import
surfaces in Vercel’s build logs
the build wall: it stops here
deploy never happens
previous deployment keeps serving
users never see the break
failure class 2
missing config
env var absent
the code itself is fine
build succeeds
nothing stops at the wall
deploy happens
surfaces at runtime: the board’s error state
or a blank page, if you skipped lab step 3
operator takeaway: code failures stop at the build wall; configuration failures walk right through it and greet your users.
