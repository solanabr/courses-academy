response anatomy, before the code consumes it

the four fields verify() reads

{ "meta": { "err": null,4 "preTokenBalances": [ … before … ], "postTokenBalances": [ { "accountIndex": 2, "mint": "EPjF…Dt1v", "owner": "MERCH…", "programId": "Tokenkeg…",1 "uiTokenAmount": { "amount": "36115000", "decimals": 62 } }, … ] }, "transaction": { "message": { "instructions": [ …, { "program": "spl-memo", "parsed": "ord-1024" }3 ] } } }
1programId names the owning token program — classic Token or Token-2022. This is the check almost everyone skips.
2uiTokenAmount.amount is an exact base-unit integer as a string. Pair pre and post by accountIndex and subtract as bigints — never touch the float uiAmount.
3With jsonParsed, an spl-memo instruction arrives parsed. That parsed string is where your builder stamped the order id.
4Non-null meta.err means landed but failed. A failed transfer moves nothing, so its deltas are zero.
