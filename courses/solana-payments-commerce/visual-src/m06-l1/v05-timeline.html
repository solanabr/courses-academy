session token lifetime

one token, five minutes, one use

t = 0 — mint buyer clicks buy → your server mints the token: one authenticated round trip
the one use exactly one open of the onramp URL consumes the token
t = 5 min — expiry an unused token expires, so a leaked link dies before it can circulate
valid window — 5 minutes, or until the single use, whichever comes first
⊘ anti-pattern: cached like a price quote a real buyer is served a dead session — or worse, another buyer's binding
⊘ replayed after the first use a captured URL replayed against the same binding fails — session already consumed
