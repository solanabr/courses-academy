kora.toml · every key blocks an attack

the validation config, walked control by control

allowed_programs = [Token, Memo, ComputeBudget]
refuses any tx invoking other programs — the checkout’s exact instruction set and nothing else
allowed_tokens = [devnet USDC]
bounds fee-quoting to mints you trust
max_signatures = 2
sponsor + buyer — a 3rd signer is not your checkout
max_allowed_lamports = 1000000
caps the SOL value a sponsored tx may move
allow_durable_transactions = false
no durable-nonce lifetimes sponsored — remember this switch next lesson
[validation.price] type = "free"
merchant eats the fee — buyers are never charged
fee_payer_policy — block omitted
every fee-payer power (System transfer source, token transfer owner, nonce authority…) defaults to DENY in current source — its power is the absence of the block
seven controls; each one is a refusal the attacker meets before your SOL moves.
