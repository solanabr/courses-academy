three states, six transitions

the dunning state machine

self-loop · pull ok → record paid invoice
retry-neverretry pull → REFUSED (throws)
terminal · no way back
active
pulls landing on schedule
pull insufficient-funds · write open invoice, NO retry scheduled
settle · invoice settled → resume
open-invoice
grace — the failed renewal sits on the books as a receivable
explicit cancel · invoice survives as receivable
cancelled
late settle of an outstanding invoice allowed — state stays cancelled
pull outcome cancelled OR explicit cancel → mark cancelled
side effect on entering cancelled: enqueue RevokeAbandoned (not an edge)
every transition writes the ledger first; the state machine only reacts to pull outcomes, settles, and explicit cancels
