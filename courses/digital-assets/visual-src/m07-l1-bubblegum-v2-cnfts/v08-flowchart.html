six hops, so a failure has an address

one crate, from mint call to resolvable asset id

on-chain
1
mint
mintV2 sends metadata + leafOwner + merkleTree + coreCollection; signed by tree delegate and collection authority
fails without the collection-authority signature
2
hash & append
Bubblegum hashes the metadata into a LeafSchemaV2 leaf, appends it via the forked mpl-account-compression program — the root changes
3
log
the Noop program emits the leaf data as a transaction log — the only place it is ever written
client and indexer
4
parse index
parseLeafFromMintV2Transaction reads the leaf index (nonce) back out of that log
5
derive id
findLeafAssetIdPda: asset id = PDA(tree, leaf index)
offline, no RPC call
6
index & resolve
a DAS provider ingests the log and indexes the asset — getAsset(assetId) now resolves
lags a few seconds — the lab retries
