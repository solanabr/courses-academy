the verify gate · what a pass looks like

three lines, exact — or it didn’t happen

$ npx tsx verify-confidential.ts <mint>
ConfidentialTransferMint present
the extension’s TLV entry decoded from the live mint — read off chain, not off your script
auditorElgamalPubkey=<your base58 key>
must EQUAL ct-keygen’s base58 line exactly — “none” means the auditor never landed (fill 3 failed)
autoApproveNewAccounts=false
manual policy confirmed — true means fill 2 failed
ConfidentialMintBurn present; supplyElgamalPubkey=<supply key>
optional fourth line — appears only on the solo supply branch
the pass is all three lines together — one wrong line points at exactly which fill failed
