node = sha256( pubkey ‖ unlocked ‖ locked )
leaf = sha256( 0x00 ‖ node )
0x00 = leaf domain tag. Leaves and internal nodes hash under different prefixes, which stops a second-preimage attack that passes an internal node off as a leaf.
