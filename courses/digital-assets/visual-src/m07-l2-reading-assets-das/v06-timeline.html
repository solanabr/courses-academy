the provider section is history, not a vendor list

how provider choice became part of reading an asset

Pre-2025 SimpleHash is the default multi-chain NFT API — Solana teams treat asset reads as a solved vendor question.
2025-01-24 solana-foundation/developer-content is archived — official education frozen before Bubblegum v2 and the MplCoreAsset / MplBubblegumV2 interfaces existed.
2025-03-27 SimpleHash shuts down its public API after the Phantom acquisition.
After on Solana the read surface consolidates on the DAS API — the choice moves from “which NFT API” to “which DAS index operator”.
