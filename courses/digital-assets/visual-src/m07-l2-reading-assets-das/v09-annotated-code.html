3compression.compressed = true → compressed-nft.das-rpc: true exactly once
4tree address + leaf id — the PDA inputs from the previous lesson.
5a real price from token_info.price_info via the provider’s MAINNET endpoint (the priced set does not exist on devnet), cached up to 600s.the gate’s printed price
6getAssetsByOwner found the Almanac asset — ownership indexing works.
7ACTIVE / DORMANT read from the raw mint, not the index. two ACTIVE metadata rows on the metadata-only devnet SPROUT; DORMANT rows show up on the PYUSD self-check.
