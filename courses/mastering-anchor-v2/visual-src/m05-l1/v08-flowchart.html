load → token movement

the spl withdraw, step by step

1
Anchor loads accounts and runs constraints
owner + discriminator inside load FIRST, then address = vault.owner
wrong signer → the address constraint fails — or a generic IllegalOwner even earlier, inside load
2
handler reads what it needs
decimals off the mint, the stored bump off the vault
3
handler rebuilds the seeds
signer_seeds = [b"vault", authority, bump]
4
handler builds TransferChecked
cpi_handle_mut (from, to)  ·  cpi_handle (mint, authority)
5
handler attaches the signature
CpiContext::new(token_program.address(), ..).with_signer(signer_seeds)
missing .with_signer → the move is unsigned and the runtime rejects it
6
transfer_checked CPI fires
the token program verifies the seeds reproduce the vault PDA
7
token program checks decimals, then moves the balance
the asserted decimals must match the mint
wrong decimals → transfer_checked refuses before moving anything
8
handler debits the vault's books
Vault.balance.checked_sub(amount)
- instead of checked_sub → panic on underflow instead of a clean error
yellow band the failure that step produces — match your error to the step, not to the whole instruction.
