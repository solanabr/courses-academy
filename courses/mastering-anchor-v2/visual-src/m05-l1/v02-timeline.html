why the interface types collapsed

how InterfaceAccount<T> became an alias

pre-v2
the slow path
Account<T> eagerly deserialized on every load. the community named it “the slow path” and “the #1 performance complaint from Anchor developers.”
the manifesto
#4390: zero-copy by default
Anchor issue #4390 — make the base Account<T> lazy / zero-copy. so nobody pays for deserialization they do not use.
v2
Account<T> is the fast path
There is no longer a separate, faster interface type to reach for. so InterfaceAccount<T> is defined AS an alias of Account<T>.
read it as the interface type did not disappear — the base type caught up with it.
