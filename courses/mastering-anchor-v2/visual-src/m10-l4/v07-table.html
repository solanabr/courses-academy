read it as
“V2 is faster” = “V2 is production-ready”
Speed and audit sit on different axes; the benchmarks are alpha-caveated and the code is unaudited.
Speed argues for your next learning build — not for user funds this quarter.
No stable date = “soon”
A missing date carries no timing information at all — in either direction.
Plan against what is committed (nothing); let a real date move the plan.
“No other V2 course exists” = a law
It is one exhausted-search result, not a theorem.
State it as a dated finding, honestly open to being wrong.
A skipped topic = an unimportant topic
Every omission here was a handoff to a named sibling course.
Skipped means owned elsewhere — not safe to ignore.
