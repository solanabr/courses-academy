the fix
Take an UncheckedAccount — no load-time owner check to short-circuit — and put the same constraint on it. Now the hook is the only owner check, so it carries your error.
#[account(owner = X @ MyErr)]
pub thing: UncheckedAccount,
MyErr is what the client sees, every time.
on the escrow's own vault field
Ship address = escrow.vault @ WrongVault, not owner = ... Owner pins the account to a program; address pins it to the account this escrow recorded — strictly stronger. Reach for owner = only when any account from that program is acceptable.
consequence On a bad owner, load fails at step 1 — the hook carrying MyErr is never reached, and the client sees IllegalOwner instead.
