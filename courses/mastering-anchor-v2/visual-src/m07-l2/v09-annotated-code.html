class 7 · arithmetic overflow

the same over-withdraw, twice

shared input
balance = 30  ·  amount = 100
an over-withdraw: the caller asks for more than the vault holds
rawwraps, or panics
vault.credit = vault.credit - amount;
release build — u64 underflow: the vault “gains” money
vault.credit becomes
18446744073709551546
debug build — panics
Neither build rejects the withdrawal.
checkedrejects
vault.credit = vault.credit .checked_sub(amount) .ok_or(VaultError::Underflow)?;
checked_sub(30, 100) → None
? returns Err(VaultError::Underflow)
The over-withdraw is REJECTED — credit unchanged at 30.
