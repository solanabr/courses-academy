the deserialize tax, v1 versus v2

V1 (Borsh)
Account<T>
cost scales with struct size — paid whether or not you read the field
load
borrow bytes → check discriminator → Borsh::decode ENTIRE struct onto stack
decode whole struct
use
mutate the stack copy
exit
Borsh::encode ENTIRE struct back into the buffer
encode whole struct
V2 (zero-copy)
Account<T>, T: Pod
cost is a pointer cast — independent of struct size
load
borrow bytes → check discriminator → cast &bytes[8..] as &Cabinet
one cast
use
read/write the field directly in the buffer
mutate in place
exit
nothing to encode; the buffer already holds the new value
no-op
the tax V1's yellow boxes grow with your struct. V2 has none of them.
