seeds and bump: a required pair

payer = player,2

+ Vault::INIT_SPACE,

pub vault: Account<Vault>,
1
init
create the account inside this instruction.
2
payer = player
the player's lamports fund the rent for the new account.
3
space = DISCRIMINATOR.len() + INIT_SPACE
8 bytes of discriminator plus the Pod body. In V2 you write it this way — never a magic 8.
4
seeds = [b"vault", player.address().as_ref()]
the namespace: a constant prefix plus the per-player key. This is what makes the address distinct and re-derivable.
5
bump
bare, with no = expr: derive the canonical bump now and hand it to the handler as ctx.bumps.vault.
seeds names the address, bump proves it is the canonical one — they are a required pair, and neither one works alone.
