where the flamegraph comes from

how anchor test --profile makes an svg

0
anchor test --profile
one command, five things happen
1
compile program in DEBUG
keep the DWARF symbols — that is what names the frames
2
run each LiteSVM test as normal
no new fixture, no new assertions — your existing tests
3
capture the per-instruction CU trace
resolve every frame back to a function via DWARF
4
write one flamegraph SVG per test
into target/anchor-v2-profile/
caveat — read the numbers this way
DEBUG build ⇒ these CU numbers are relative shape, NOT release cost.
