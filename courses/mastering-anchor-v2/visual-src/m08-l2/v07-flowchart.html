squads v4 · ordered handoff

moving upgrade authority to a multisig

MAINNET-ONLY Beyond this course's cluster — read it, do not run it on devnet expecting the same guarantees.
1 Create the Squad the multisig itself: its members and the approval threshold, decided before anything is handed over
2 Write the new bytes to a buffer the upgrade payload lands in an on-chain buffer account — staged, not yet live
3 Set the buffer's authority to the Squad the first authority move — the buffer only, not the program authority move
4 Transfer the program's upgrade authority to the Squad the second authority move — your key stops being able to upgrade alone; in practice you do not get it back authority move
5 Create the proposal apply-the-buffer becomes a proposal the members can read before it executes
6 Approve to threshold → execute once enough members approve, the upgrade executes and the new bytes go live
Steps 3 and 4 are the two authority moves — the hops you cannot casually undo. Everything before them is staging.
The Squads v4 program has been immutable since Nov 2024 — the multisig you are trusting cannot itself be upgraded.
