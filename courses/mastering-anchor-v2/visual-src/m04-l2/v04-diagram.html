one instruction, top to bottom

the CpiHandle owns the borrow for its whole scope

handle NOT yet created
no borrow outstanding
typed access ALLOWED
Reading the account you are about to hand the CPI is legal — no borrow exists yet.
borrow starts
the handle is created
let cpi = CpiContext::new(&sys, Transfer { from: vault.cpi_handle_mut(), .. });
handle LIVE, borrow held
the exclusion window
typed access EXCLUDED — for the CPI’d account
Reading vault here is a compile error. Accounts you did not hand the CPI stay readable.
borrow ends
the handle drops
transfer(cpi, amount)?;   // cpi is consumed here -> handle drops
handle dropped
borrow released
typed access ALLOWED AGAIN
And the read now returns the LIVE account — nothing to reload.
