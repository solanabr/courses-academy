the failing line and the fix

the only change is the order

before WILL NOT COMPILE
let cpi = CpiContext::new(token_program.address(),
TransferChecked { from: vault_ta.cpi_handle_mut(), .. });
let before = ctx.accounts.vault_ta.amount(); // E0502: cpi still holds vault_ta's mut borrow
transfer_checked(cpi, amount, decimals)?;
after COMPILES
let cpi = CpiContext::new(token_program.address(),
TransferChecked { from: vault_ta.cpi_handle_mut(), .. });
transfer_checked(cpi, amount, decimals)?; // cpi consumed here -> handle drops -> borrow released
let after = ctx.accounts.vault_ta.amount(); // now legal, and reads the LIVE account
The handle drops when transfer_checked consumes cpi; the read that follows is legal and fresh.
The only change is the ORDER. No reload(), no clone, no new call — the read simply moved below the line that drops the handle.
