has_one → address: a rename, not a new idea

before — V2 deprecated
compiles, with a warning
#[account(has_one = maker)]
pub escrow: Account<Escrow>,
means
escrow.maker == maker.address() — one fixed shape: field name matches account name.
same check, expression-based
after — V2 idiomatic
no warning
#[account(mut, address = escrow.player)]
pub player: Signer,
means
player.address() == escrow.player — any expression allowed on the right.
migration
the compiler underlines the deprecated form for you — this is a guided rename, not a redesign.
