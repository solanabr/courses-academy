what the install actually pins

Reading the RC install command flag by flag

CARGO_PROFILE_RELEASE_LTO=off cargo install --git https://github.com/otter-sec/anchor.git --branch anchor-next anchor-cli --locked --force
Each token below is highlighted in the command above. --branch anchor-next and --locked are the two that matter most on an RC.
CARGO_PROFILE_RELEASE_LTO=off
macOS-only; disables link-time optimization so the RC build finishes
--git <url>
build from source at this repo, not from crates.io
--branch anchor-next
pin source to the frontier branch specifically
anchor-cli
the crate inside the repo to install as a binary
--locked
honor the committed Cargo.lock — reproducible, and RC-critical
--force
overwrite any existing anchor-cli in ~/.cargo/bin
