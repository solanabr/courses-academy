cu_swap_regression · what it asserts

a budget you earned, not a number you guessed

1  ·  the budget
const TRADE_CU_BUDGET: u64 = <your AFTER> + <headroom>;
2  ·  behaviour first
process_and_validate_instruction(.., &[Check::success()]);
3  ·  the core assertion
result.compute_units_consumed <= TRADE_CU_BUDGET
4  ·  the message
assert!(.., "trade regressed: {} CU ..");
the budget
The budget is the number you earned, not a guess — the headroom absorbs ordinary noise.
behaviour first
First prove the swap still works. An optimization that breaks behaviour is not a win.
the core assertion
At-or-below, not equality. A future change that gets cheaper passes; one that regresses fails.
the message
The failure prints both numbers, so the next dev sees the regression — not a bare panic.
