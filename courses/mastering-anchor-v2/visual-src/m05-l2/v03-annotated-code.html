The fee is taken before the curve — and the promotion to u128 starts right here.
the critical line · overflow
The one multiply that can overflow even u128 — the ×997 spent the headroom. checked_mul hands back None; the match turns it into “no quote”, never a wrap.

Keeps the 997/1000 scale consistent; reserve_in > 0 means the denominator is never zero.

Integer division rounds DOWN, in the pool’s favor; output ≤ reserve_out, so the cast is safe.
