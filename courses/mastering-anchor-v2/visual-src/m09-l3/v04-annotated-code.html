the reusable template

every V2 CPI is these three parts

placeholders — swap <rung> for the vault, escrow or swap, and <Instruction> for its instruction
1
the accounts struct from the callee’s cpi module — one CpiHandle per account
let cpi_accounts = <rung>_cpi::accounts::<Instruction> { writable_account: ctx.accounts.x.cpi_handle_mut(), // callee will write it readonly_account: ctx.accounts.y.cpi_handle(), // callee only reads it };
2
CpiContext::new with the callee program id via .address() — an &Address in V2
let cpi_ctx = CpiContext::new(ctx.accounts.<rung>_program.address(), cpi_accounts);
…or .with_signer(seeds) / new_with_signer(..) when a PDA of YOURS must sign
3
the generated wrapper packs the args and invokes
<rung>_cpi::<instruction>(cpi_ctx, ..args)?;
rule
Read any typed state you need before step 1 — once the handle borrow is taken, the typed read will not compile.
