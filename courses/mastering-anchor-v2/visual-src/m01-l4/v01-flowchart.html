what #[derive(Accounts)] generates

Load, then constrain, then dispatch

Phase 1
LOAD
deserialize each field into its typed wrapper
Account<T>
owner check + 8-byte discriminator check
Signer
signature bit check
Program<T>
address + executable check
Fail here and it stops before any constraint runs.
only if the previous phase passed
Phase 2
CONSTRAINTS
the #[account(...)] hooks fire
mut init seeds + bump has_one constraint = ...
They need the loaded data, so they run AFTER load.
only if the previous phase passed
Phase 3
DISPATCH
hand validated accounts to the handler
ctx.accounts → handler body
The handler body runs LAST, never first.
