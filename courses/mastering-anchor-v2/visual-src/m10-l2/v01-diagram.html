one migration · three roots

three decisions, every delta downstream

decision 1
no_std rewrite on pinocchio
types from solana-address
Pubkey becomes Address
.key() becomes .address()
<'info> lifetimes vanish; handlers take &mut Context<T>
decision 2
zero-copy is the default account model
Account<T>: Pod
the zero_copy attribute is gone
AccountLoader is repurposed (sequential cursor), not the zero-copy wrapper
state that is not Pod-legal moves to BorshAccount<T>
space = T::DISCRIMINATOR.len() + T::INIT_SPACE
decision 3
CPI is borrow-tracked
CpiHandle
.reload() is removed, not renamed
typed access during a live CPI handle is a compile error
CpiContext::new takes the program as &Address
cross-cutting
the compiler narrates the edit
has_one deprecates to address = parent.field (span-underlined)
dup becomes unsafe(dup) — plain dup is a compile error
realloc::payer becomes realloc_payer
